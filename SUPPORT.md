# Support

## Getting help

- **Bug reports and feature requests**: open a [GitHub Issue](https://github.com/raoamogh/regeval/issues).
- **Questions about usage**: open an Issue tagged `question`, or check the [README](README.md) first — the Quickstart and "How it works" sections cover the most common questions.
- **Security vulnerabilities**: do **not** open a public issue — see [SECURITY.md](SECURITY.md) instead.
- **Direct contact**: amoghagrao@gmail.com

## Response times

regeval is maintained by a single developer in their spare time. No guaranteed SLA, but issues are typically triaged within a few days.

## Before opening an issue

Please include:
- Your regeval version (`pip show regeval`)
- Python version and OS
- The suite YAML you're using (redact real API keys)
- Full error output, if applicable

If the issue involves a specific provider (Ollama, OpenAI, Groq, etc.), please mention which one — behavior can vary slightly between providers even though they share the same API shape.
